# Project terminology

## Clone

Trong dự án này, "clone" KHÔNG phải Git clone.

Clone là một game instance/profile dùng để chạy game và đăng nhập một tài khoản khác.

## Multi Clone

Multi Clone là chức năng quản lý và tự động xử lý nhiều game instances/accounts.

Khi AI phân tích code:
- Không được hiểu clone là git clone.
- Không đề xuất clone repository.
- Phải đọc code hiện tại trước khi đề xuất thay đổi.
